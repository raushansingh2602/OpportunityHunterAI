# OpportunityHunterAI 🚀

An intelligent, autonomous agent designed to help students and developers find and evaluate the best internship and job opportunities. Built during the Slum Hackathon.

## 🌟 Features
- **AI-Powered Matching**: Evaluates candidate profiles against job requirements using skill overlap, CGPA, and graduation year criteria.
- **Autonomous Search**: Uses intelligent query generation to scrape and find relevant opportunities across job boards.
- **Modern Interface**: A sleek, responsive Next.js frontend to input profiles and view AI-analyzed results.
- **FastAPI Backend**: A robust and fast Python backend connecting the AI engine with the frontend.

## 🛠️ Tech Stack
- **Frontend**: Next.js, React, Tailwind CSS, TypeScript
- **Backend**: Python, FastAPI, Uvicorn
- **AI Engine**: Custom heuristic and AI scoring models

## 🚀 How to Run Locally

1. **Start both servers automatically**:
   Simply double-click the `start.bat` file in the root directory.

*Or run them manually:*
- **Backend**:
  ```bash
  cd backend_intigration
  pip install -r requirements.txt
  python -m uvicorn backend.main:app --reload --port 8000
  ```
- **Frontend**:
  ```bash
  cd frontend-newwww
  npm install
  npm run dev
  ```
  Then visit `http://localhost:3001` in your browser.
