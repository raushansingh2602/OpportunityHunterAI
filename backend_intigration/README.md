# OpportunityHunter AI — Backend (FastAPI)

Quick start (backend):

1. Create a virtualenv and activate it.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Copy `.env.example` to `.env` and edit as needed.

4. Run the server:

```bash
uvicorn backend.main:app --reload
```

Playwright notes: If the browser agent (Person 1) requires Playwright, install it separately and follow Playwright setup.
